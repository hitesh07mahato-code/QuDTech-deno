# QuDTech — Quantum Health Detect

Hybrid Quantum Machine Learning Platform for Early Disease Detection.

A full-stack web application demonstrating quantum-classical screening workflows, encoding, entanglement, readout, attribution, and clinical-style interpretation.

## Overview

- **Interactive Risk Demo**: Simulated deterministic statevector backend with multi-marker panels.
- **Explainability & Attribution**: Per-qubit impact rankings and circuit visualizations.
- **Modern Architecture**: Powered by TanStack Start, React, Vite, and Tailwind CSS.

## Getting Started

### Prerequisites

- [Bun](https://bun.sh) (recommended) or Node.js (v18+)

### Installation

```sh
bun install
```

### Development

```sh
bun run dev
```

Open [http://localhost:8080](http://localhost:8080) in your browser.

### Build

```sh
bun run build
```
